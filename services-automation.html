01 / Who this is for

Eliminating repetitive operational overhead.

If someone on your team copies details from an enquiry email into a spreadsheet, then into an invoice, then into a WhatsApp message, a connected workflow can usually do that work. Automation suits tasks that are repeated often, follow clear rules and move information between tools you already use.

Netqorix builds workflow automations, rule-based chatbots, AI assistants, marketing sequences and custom scripts. Sanjeev scopes the work directly with you, so you automate the task that costs you the most time first, not everything at once.

Not every task should be automated. A task done twice a month, or one that needs judgement every time, is usually cheaper to keep manual. If that is your situation, you will be told so.
02 / Problems this can address

Manual double-entry, missed leads and slow response times.

Manual double-entry.

The same details are typed into a form, a spreadsheet and an invoice. Every re-type is a chance for an error.

Missed leads.

Enquiries arrive through the website, WhatsApp and email, and one of them sits unseen until the next day.

Slow response times.

A customer who waits hours for a reply often contacts someone else.

Follow-ups that depend on memory.

Quotes, reminders and payment follow-ups happen only when someone remembers.

Reports built by hand.

Figures are collected from several tools and pasted together every week.

Systems that do not talk to each other.

Your CRM, accounts, forms and messaging tools each hold part of the picture.

Some of these problems come from an unclear process, not a missing tool. Where that is the case, the process is fixed first, because automating a broken process only makes it fail faster.

03 / How it works

Triggers, webhooks, LLM agents and error handling.

Triggers and actions.

A trigger is something that happens: a form is submitted, an email arrives, a payment is received. The actions are what happens next: save the lead, send a reply, notify your team.

Webhooks and APIs.

A webhook lets one application tell another the moment something happens, without anyone checking. APIs let the two tools exchange data. Most workflows are built from these two pieces.

Rule-based bots.

A rule-based chatbot follows a script you approve. It gives the same answers every time, which suits FAQs and lead capture where wording must be controlled.

LLM agents.

An LLM agent is an AI assistant, such as a GPT or Claude-powered one, that reads a question and writes an answer from a knowledge base you provide. It handles varied wording but can occasionally be wrong, so it is set up with limits and a route to a human.

Error handling.

Tools and APIs fail sometimes. Each automation is built with a defined response: retry, alert you, or stop safely, rather than failing without anyone noticing.

Rule-based versus AI is a choice, not an upgrade. If the answers must be exactly the same every time, a scripted bot is the safer and cheaper option.

05 / What you get and what is excluded

Workflow documentation and testing checklists.

Included in the agreed scope:

  • The working automation, built to the approved scope.
  • Workflow documentation: what triggers it, what each step does and which tools and data fields it uses.
  • A testing checklist, completed before the automation goes live.
  • Error handling and failure alerts as agreed in the scope.
  • The agreed accounts, credentials and access, handed over after final settlement.
  • Source code for custom scripts and an exported copy of each workflow, where the platform allows it.

Not included unless quoted separately:

  • Tool subscriptions and plans: Zapier, Make, n8n hosting, CRM and similar.
  • LLM API usage charges, WhatsApp Business API fees and provider approval processes.
  • Cleaning or restructuring existing data before it is connected.
  • Changes after handover. See Automation Maintenance above and maintenance and support (/services-maintenance).
  • Guaranteed AI accuracy. An LLM bot can be wrong; limits and handover rules are set up, not eliminated.
  • Workflows or features discussed but not written into the approved scope.

07 / The delivery process

Process mapping, staging runs and fail-safe setups.

STEP 01
Share the process

Describe the manual steps, the tools involved and how often the task happens. Screenshots of the current sheets, forms or inboxes help.

STEP 02
Map and scope

Sanjeev maps the process, decides what to automate and what to leave manual, and issues a fixed quote with deliverables, exclusions and payment milestones.

STEP 03
Build and staging run

The automation is built and tested with sample data in a staging setup, not on live customers.

STEP 04
Fail-safe setup

Error handling, retries and failure alerts are configured, with a manual fallback so work does not stop if a tool is down.

STEP 05
Go live and handover

The automation goes live after the testing checklist is complete. Documentation, access and credentials follow final settlement.

Timelines depend on the number of tools connected and how quickly access and approvals come back. A delivery schedule is confirmed in your quote rather than promised in advance on this page.
08 / Pricing, billing and running costs

API token consumption and platform subscriptions.

One-time project cost:

The build is billed per project at the rate above, 50% to start and 50% on delivery. If the scope changes mid-project, the change is quoted and approved separately before it is built.

Recurring costs to budget for:

Automations run on other companies' platforms. Plan for subscriptions to tools such as Zapier, Make or a hosted n8n, any CRM you connect, WhatsApp Business API charges, and API token consumption for AI assistants. LLM costs rise with the number of conversations and the length of each answer. These are billed by those providers, and amounts depend on your usage.

Keeping automations working:

Apps change their APIs, tokens expire and fields get renamed. An automation that is not monitored eventually stops working, often without anyone noticing. Automation Maintenance covers monitoring and fixes as a monthly retainer.

Netqorix itemises these in your quote so you can see the one-time build and the ongoing bill before you commit.

FAQ

Automation & bot questions.

Do I need automation or just a better process?
If the task is unclear, changes every time or happens rarely, fix the process first or keep it manual. Automation pays off for tasks that repeat often and follow clear rules. You will get a direct answer on which you need, including when the answer is "not yet".
What is the difference between a rule-based chatbot and an AI agent?
A rule-based bot follows a script you approve and gives the same answer every time. An AI agent reads the question and writes an answer from a knowledge base you supply. The first is cheaper and more predictable; the second handles varied wording but can occasionally be wrong.
Can an AI chatbot give wrong answers?
Yes. No provider can promise that an AI model is always correct. The assistant is set up with a defined knowledge base, limits on what it answers and a route to a person when it is unsure, which reduces the risk but does not remove it.
Which tool will you use: Zapier, Make or n8n?
It depends on the number of steps, the volume of runs, the apps involved and where your data may be stored. The tool is chosen and written into the scope before work begins, and you see its subscription cost up front.
Who owns the automation?
Under the standard engagement terms, source code, scripts and assets are transferred to you on final invoice settlement. Platform accounts are set up in your name wherever the tool allows it.
What happens if an automation fails?
Each automation is built with error handling agreed in the scope, such as retries and an alert to you. Ongoing monitoring and fixes are covered by the Automation Maintenance retainer.
Are subscription and API costs included?
No. Tool subscriptions, LLM API usage and WhatsApp Business API fees are billed by those providers at cost or paid directly by you, and itemised in your quote.
Can a bot work on WhatsApp?
Yes, using WhatsApp Business. It needs a WhatsApp Business API account and the provider's approval, and the provider's charges are separate from the Netqorix build.
How is my business data handled?
Access is limited to what each workflow needs, and credentials are held in the platform's own secure settings. Specifics for your tools are confirmed in the scope before work starts.
